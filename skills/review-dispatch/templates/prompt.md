## 出力形式

以下の表だけを返す。表以外に書けるのは末尾の `未確認事項:`（最大 3 行）のみ。全体 60 行以内。

| Severity | Location      | Finding | Evidence | Suggested fix |
| -------- | ------------- | ------- | -------- | ------------- |
| MUST     | app/foo.ts:42 | …       | …        | …             |

- Severity: MUST（目的が満たされない／直さないと重大な欠陥）／NITS（挙動は同じだが直した方がよい）／
  IMO（より良い実装への提案）
- Location は `path:line`。行が特定できなければ `path` のみ。
- 同じ原因が複数箇所にある場合は代表 1 行を挙げ、他を括弧で添える
  （例: `app/a.ts:12`（also: `app/b.ts:30`））。
- **Evidence には `{{EVIDENCE}}` 内の該当箇所（節番号か `path:line`）を書く。** 事実パックに
  根拠が無い指摘は書かない。書きたければ「未確認事項」に 1 行で置く。
- 指摘が無ければ `No findings` とだけ書く。
